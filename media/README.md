# Media Klasörü (Bezel Görselleri)

Bu klasör, `bezeller.html` sayfasındaki saat bezel görsellerini barındırır.
Kendi beğendiğiniz yüksek çözünürlüklü fotoğrafları veya görselleri bu klasöre aşağıdaki isimlerle ekleyerek sayfayı kişiselleştirebilirsiniz:

- **`dalgic-bezel.jpg`** — Dalgıç Bezeli (Diver's Bezel)
- **`takimetre-bezel.jpg`** — Takimetre (Tachymeter)
- **`gmt-bezel.jpg`** — GMT Bezeli (24 Saat Halkası)

### İpuçları:
- Kare formatındaki görseller (örneğin 600x600, 800x800 veya 1000x1000 piksel) en iyi sonucu verir.
- JPG yerine PNG kullanmak isterseniz (`dalgic-bezel.png` vb.), sistem otomatik olarak PNG yedeğini de algılar.
- Yeni bir görsel eklediğinizde veya değiştirdiğinizde web sayfasını yenilemeniz (F5 veya Ctrl+F5) yeterlidir.
